# 前端重构设计文档

## 概述

对 oci-start-go 前端进行全面重构，覆盖用户体验、视觉一致性、代码质量三个维度。采用渐进式重构方案，核心页面优先，保留现有 "Operator" 暗色设计系统并优化。

## 项目背景

- **技术栈：** Vue 3 + Element Plus + TypeScript + Vite
- **设计系统：** 暗色 "Operator" 主题，CSS tokens 完善
- **页面数量：** 20 个页面
- **约束：** 纯前端重构，API 不变

## 痛点分析

1. **视觉不精致** — 样式不统一，部分页面看起来粗糙
2. **交互流程复杂** — 弹窗嵌套多，操作步骤繁琐
3. **响应式不足** — 移动端体验差，表格横向滚动

## 重构范围

### 核心页面（优先级高）

1. Dashboard（仪表盘）
2. TenantList（租户管理）
3. TenantDetail（租户详情）
4. Instances（实例管理）
5. Settings（系统设置）

### 基础设施

1. 公共组件层提取
2. Layout 优化（侧边栏分组、移动端适配）

---

## 设计方案

### 1. 公共组件层

提取 8 个可复用组件，解决各页面重复代码问题。

| 组件 | 用途 | 当前状态 |
|------|------|----------|
| `PageHeader` | 页面标题 + 操作按钮区 | 各页面重复写 `.toolbar` |
| `StatusCard` | 统计卡片（数字 + 状态） | Dashboard 专用 |
| `FilterBar` | 筛选栏（搜索 + 下拉 + 标签） | Instances 有，TenantList 无 |
| `EmptyState` | 空状态占位 | 用 el-empty，无统一风格 |
| `ConfirmDialog` | 确认操作弹窗 | 各页面重复 ElMessageBox |
| `InlineEdit` | 行内编辑（输入 + 保存） | Settings 页面重复写 |
| `StatusBadge` | 状态标签（颜色 + 图标） | 各页面样式不统一 |
| `MonoText` | 等宽文本（IP、ID、时间） | 用 `.data-mono`，不统一 |

**目录结构：**

```
src/components/common/
├── PageHeader.vue
├── StatusCard.vue
├── FilterBar.vue
├── EmptyState.vue
├── ConfirmDialog.vue
├── InlineEdit.vue
├── StatusBadge.vue
└── MonoText.vue
```

**设计原则：**

1. 一个组件一件事
2. Slots 优先于 Props
3. 样式使用 CSS tokens
4. 响应式内置
