## 🎭 特殊效果

### 动画
1. **淡入** (`fadeIn`): 0.3s 淡入效果
2. **滑入** (`slideInLeft`): 从左侧滑入
3. **脉冲** (`pulse`): Logo 轻微脉冲
4. **渐变动画**: 登录页背景渐变流动

### 过渡
- 所有交互元素都有 `0.3s cubic-bezier(0.4, 0, 0.2, 1)` 过渡
- 按钮悬停时的 transform 动画
- 菜单项平滑展开/收起

### 悬停效果
- 卡片上升并增加阴影
- 按钮缩放和发光
- 菜单项背景变化

## 📱 响应式设计

所有组件都进行了响应式优化：
- ✅ 平板设备 (≤ 768px)
- ✅ 手机设备 (≤ 480px)
- ✅ 超大屏幕

### 断点
- `@media (max-width: 768px)`: 平板和手机
- `@media (max-width: 480px)`: 小屏幕手机

## 🎯 使用指南

### 应用新样式
1. 全局样式自动通过 `src/main.ts` 导入
2. 在各个 `.vue` 文件中使用 `<style scoped>` 进行本地定制
3. 使用 CSS 变量实现主题一致性

### 添加新组件样式
```vue
<style scoped>
/* 使用 CSS 变量 */
color: var(--text-primary);
background: var(--bg-primary);
box-shadow: var(--shadow-md);

/* 使用渐变 */
background: linear-gradient(135deg, var(--primary-color), var(--primary-light));
</style>
```

### 常用 CSS 类和工具
- `.fade-in`: 淡入动画
- `.slide-in-left`: 滑入动画
- `--shadow-*`: 阴影变量
- `--primary-color`: 主色变量

## 🔧 自定义调整

### 修改主色调
编辑 `src/style.css` 中的 CSS 变量：
```css
:root {
  --primary-color: #0066ff;        /* 修改主色 */
  --primary-light: #3385ff;        /* 修改浅色 */
  --primary-dark: #0052cc;         /* 修改深色 */
}
```

### 修改间距
所有间距值都使用具体的 px 值，可根据需要调整：
- 卡片内间距: `padding: 24px`
- 组件间距: `gap: 20px`
- 边距: `margin-bottom: 28px`

### 修改圆角
- 卡片: `border-radius: 16px`
- 按钮: `border-radius: 8px`
- 输入框: `border-radius: 8px`

## 📊 性能考虑

- ✅ 使用 CSS 变量减少重复代码
- ✅ 渐变使用 `linear-gradient` 而非图片
- ✅ 阴影使用 `box-shadow` 而非图片
- ✅ 动画使用 CSS 而非 JavaScript
- ✅ Transform 用于性能优化的动画
